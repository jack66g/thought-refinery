# RSI 设计文档

## 现行设计与边界

ThoughtRefinery 以常驻 daemon 为核心，通过 MCP 或 HTTP 接收宿主的多轮和推理事件。RSI 管理队列和本地数据，空间记忆由独立 SME 服务通过 REST 提供。业务仍保留 CoT、个人底色预训练、风格 SFT 三条数据线及四层仿生画像。自驱出题和领取自探索任务的开关独立，配置默认关闭。

- CoT 先做价值与过程审计，修复结果需要复审。FCS 和净化产生候选，经过复审才可替换已审计文本。答案比较在本地完成，独立求解只接收题面。未配对 DPO 留作候选，LEMA 仅使用通过双门的纠正。
- 观察者使用用户原话。主观事实与叙事证据指向同一用户引文。风格 SFT 将用户原话作为 assistant 目标，在保留语气和标点的同时对敏感字段做替换。
- 接收、运行与 CoT 分支检查点存放在本地 SQLite 台账。宿主可提供会话与源事件 ID，旧客户端按内容归并。三条训练输出仍为原有 JSONL 布局。
- 模型费率和日预算由 daemon 配置控制。真实模型调用先持久化保守预留，回包有 usage 时按配置费率更新。跨供应商使用时按对应模型费率配置。
- 仿生参数表继续作为验收基准。源事件捕获时间和落盘时间分开记录。运行记录与逐次验收见 [台账文档](台账文档.md)，后续任务更新放入 [计划书](计划书.md)。
- 下列原始设计和研究随仓库保留，正文中出现的旧目录项或实现状态代表当时基线。

## 情境选择模式

选择模式使用本机网页和独立的作答记录。默认关闭。在 `daemon.json` 中配置 `choice_mode.enabled` 为 true，使用正常 daemon 入口启动时会打开 `/choice`。也可从该网页开关，浏览器里的改动由当前运行数据目录保存。显式修改配置中的初始开关后，以新的初始值为准。`open_browser` 控制后台是否自动打开浏览器。关闭时保留已答题目，对同一轮可以续答。

- **题量与门槛**。每天 3 轮，每轮两题，题量可按 1–6 轮配置。默认在 12 次画像更新和至少 6 条去重主观事实记忆后出题。点开始时才调用模型。两题的有效选项均随机排序，可略过其中任一题。略过占用当日轮数，用于约束生成开销。
- **题目与抽样**。第一题从画像和脱敏记忆拟合虚构情境，第二题针对已选做法拟合可选理由。当天可沿用上一轮的故事背景。隐去测量方向，轮换现实题材，优先补测风险余地、行动节奏、协作方式、探索偏好、计划弹性中记录最少的维度。
- **计分**。完成后给第一题的单侧选择记一次方向观测，折中各记半次。理由记录本轮动因，避免给同一轮加第二份计分权重。每个维度用两侧各 2 个伪计数向中性收缩。该维至少有 3 个有效轮次、覆盖至少 2 类情境时显示个人内的观察比例。设计借鉴跨情境状态分布和强迫选择测量对解释口径的限制，当前维度、阈值和比例仍属产品估计，待独立样本校准信效度。 [Fleeson](https://pubmed.ncbi.nlm.nih.gov/11414368/) · [Brown、Maydeu-Olivares](https://kar.kent.ac.uk/30530/)
- **数据**。完整作答共享一个事件 ID，并输出 `pretrain/choices.jsonl` 与 `style/choices.jsonl`。前者写条件性自述，后者写用户选定的做法与理由，训练目标均标记为模型拟写、用户确认的选项。冻结时按同一事件及当天故事分组，历史事实与虚构情境的来源标签各自保留。选择模式写到独立作答状态和人格产物，沿用现有模型预算。

## V2 常驻提纯设计

> 版本：v2（2026-11-22）。**推翻 v1 的批处理架构，保留其提纯内核。**
> v1 → v2 的三个根本转变：
> 1. 形态：按批跑的离线管线 → **常驻守护进程 + MCP 插件**（每时每刻运行）
> 2. 领域：数学起步 → **全域摄取**（对话、出题、日常聊天、项目干活，一切产生思考的地方）
> 3. 沉淀：单一数据集 → **分类数据区**（大类 + 杂项，产出直接可训练）
> 依据：`01_调研笔记_CoT提纯与RSI循环.md`（引用 [A*/B*] 均指该文档）。

### 1. 一句话定位与体验契约

**一个 7x24 常驻的思考提纯插件（MCP 插件，挂载进宿主）**：像 SME 一样以 MCP 工具的形式挂进 ZCode、其他自动化编程工具或任意 MCP 宿主；用户照常在宿主里聊天、干活、跑项目——插件在后台把一切思考流（连同守护进程的自驱出题）异步提纯、判定价值、分类沉淀为标准训练数据；SME 作为它的长期记忆与分类索引；循环基于运行经验自进化，无人监督。

**用户体验契约**：宿主就是入口。用户在 ZCode/编程工具里的体验**零变化**——不做自己的前端、不做自己的聊天页、不为积累数据多点一下或多说一句；一切积累在后台静默发生，只留有价值的。

### 1.1 工程铁律：零源码污染，纯接线

1. **SME 一行源码不碰**：只用它的公开接入面——REST API（`python -m sme.api` 常驻）+ `MemoryClient` SDK + MCP 挂载。SME 升级、回滚、换版本，接线不受任何影响。
2. **宿主一行源码不碰**：RSI 对宿主（ZCode 等）也是纯插件——MCP server 挂载 + 宿主侧一句指令约定（AGENTS.md 里告诉 agent"任务结束把思考轨迹喂给 rsi 工具"，与 SME 的 remember/recall 用法同款），不改宿主任何代码。
3. **全部新代码放独立文件夹**：`RSI(无权重版本）/rsi/`（与 `spatial-memory-engine/` 平级、零耦合）。
4. **一切 LLM 走 OpenAI 兼容 API**：出题、解题、提纯、判类共用一个客户端，换服务商只改配置。
5. 接线总图（谁连谁、走什么协议）：

```
宿主（ZCode / 自动化编程工具 / 任意 MCP 宿主）⇐ 用户照常在这里聊天干活
  │ 挂载 rsi MCP server（工具被宿主 agent 调用即投喂，或宿主 hook POST /ingest）
  ▼
RSI 守护进程（rsi/daemon/，Python asyncio 常驻，本地）
  ├─ 摄取队列：宿主投喂的思考尾迹（异步消化，不打扰宿主）
  ├─ 提纯内核：判类 → 价值门 → 体检/审计/修复/净化/复验 → 分类数据区（本地 jsonl）
  ├─ 自驱出题：空闲时自己出题自己解（保底循环，宿主没人用也不停）
  └─ 索引卡/教训/血统/统计 ──只用 MemoryClient/REST──► SME
                                          ▼
SME（spatial-memory-engine/ 原样运行，一行不改，python -m sme.api 常驻）
```

四个平面一句话：
- **摄取面**：不限定领域、不限定来源；对话尾迹与自驱出题保底，宿主内干活也吃。
- **提纯面**：判类 → 价值门 → 内核提纯（v1 内核原样继承，验证分级改造）。
- **沉淀面**：按大类分区的训练数据 + SME 分类索引，**产出即直接可训练**。
- **进化面**：meta-learner 三件事——进化提示词、进化教训、进化分类本身。

### 3. 摄取面设计（"每时每刻"怎么实现）

摄取通道（重新定义——**入口在宿主，我们是插件**）：

| 通道 | 触发 | 机制 | 落地优先级 |
|---|---|---|---|
| **T0 宿主插件通道** | 用户在 ZCode/自动化编程工具里正常干活、聊天 | rsi 以 MCP server 挂载进宿主；宿主 agent 按 AGENTS.md 约定调用 `rsi_distill` 投喂任务尾迹（与 SME 的 remember/recall 同款用法）；或宿主 hook 直接 POST `/ingest` | **第一**——插件本体，不做自己的前端 |
| **T1 自驱出题** | 守护进程空闲（队列空 + 预算内） | meta-learner 依据 SME stats 自选领域出题（哪类数据少/哪类错误多练哪类）→ 自己解 → 进提纯内核 | **保底通道**（宿主没人用也永不停转） |
| **T2 其他宿主/机器人** | 其他 MCP 宿主、聊天机器人接入 | 同 T0 机制（MCP 挂载 + 一句指令约定）；非 MCP 的走 `/ingest` HTTP | 后做（一个薄适配器） |

关键原则：**摄取永远异步**——思考事件进队列，守护进程按自己的节奏消化，绝不拖慢宿主（用户感知不到提纯存在）；队列有积压上限，满了丢最低价值事件（价值门前置到入队时做粗筛）。

宿主侧接线成本（以 ZCode 为例，一次性）：
1. MCP 配置里挂 `rsi` server（一行 JSON，与挂 SME 同款）；
2. 项目 AGENTS.md 加一句约定："每完成一个任务/一段有思考含量的对话，把思考轨迹与结论调用 rsi_distill 投喂"。就这两步，宿主代码零改动。

### 4. 判类器与分类区设计（"数学、语文……大类 + 杂项"）

#### 4.1 分类体系

- **大类（一级）= SME 命名空间 + 数据集目录**，v2 固定五个起步：
  `math`（数学/逻辑/可符号验证）、`chinese`（语文：写作/摘要/翻译/语言表达）、`code`（代码/工程）、`reasoning`（常识/分析/决策类推理）、`misc`（杂项：判不进前四类的一律进这里）
- **细分（二级）= tags**，不建目录不建 ns（"不需要分很细"）：如 `math.不等式`、`chinese.摘要`、`code.调试`。
- 判类器 = 便宜档 LLM 一次调用（输入：题目/任务的短摘要），输出大类 + tags + 置信度；置信度低 → `misc`。**宁进杂项不硬塞**。

#### 4.2 misc 的自进化（进化面职责之一）

meta-learner 每 N 批复盘 misc：embedding 聚类，若出现稳定大簇（如占比 >20% 且内部相似度高）→ 向数据区提议新大类（写提案进 `rsi.lessons`，人拍板后才开新 ns/目录）。分类体系本身是进化对象，但开新类的决定留人——防止类目爆炸。

#### 4.3 数据区目录

```
rsi/dataset/
├── math/     {sft,lema,dpo}.jsonl   # 追加写，按批滚动
├── chinese/  …
├── code/     …
├── reasoning/…
├── misc/     …
└── _meta/    质检报告、类别统计、mixing 建议（各类占比与训练配比参考）
```

**"直接拿去训练"的含义**：每条都是统一 messages+`<think>` 格式（v1 §5 格式原样沿用）、带血统元数据、通过对应类的验收门；`_meta/` 附 mixing 建议（各类占比、lema 占比 5-10%、去重声明）。拿走即训，不需要再清洗。

### 5. 价值门设计（"不是什么都存，只存有价值的"）

两级门控，**先粗后细，便宜的在前面**：

#### 5.1 入队粗筛（零 LLM 成本，规则）

丢弃：纯寒暄/无思考内容（思考段为空或 <50 token）、重复入队（同题同内容哈希）、超长截断残迹、语言混杂严重。

#### 5.2 价值评分（一次便宜 LLM 调用，结构化输出 0-10 分）

五个维度（全部无监督信号）：

| 维度 | 信号 | 说明 |
|---|---|---|
| 可验证性 | 有无硬验证通道 | 数学/代码可验 > 不可验 |
| 认知密度 | 单位 token 的推理步数/方法含量 | 有可复用方法 > 平铺直叙 |
| 新颖性 | 与该类既有库 embedding 最大相似度 | 太相似 = 低价值（ novelty 反用，ShinkaEvolve [B3]） |
| 非模板性 | 与既有数据 n-gram 重复率 | 高重复 = 低价值 |
| 完整性 | 思考是否闭环（有结论、无断裂） | 断裂直接丢 |

- 可验证类（math/code）：**分数只是排序用，能不能进主集仍由硬验证双门决定**（价值分 ≠ 正确性）。
- 不可验证类（chinese/reasoning/misc）：价值分 + 软验证（§6）共同决定去留，阈值由 meta-learner 按类自适应调整（每类维护自己的接受率目标，防止某类饿死或泛滥）。
- **被丢弃的也留一行"弃单记录"进 `rsi.stats`**（只记原因不记内容）——meta-learner 需要知道丢了什么才知道该把门调松还是调紧。

### 6. 验证分级（无监督的诚实边界）

"尽量不需要监督"的现实做法是把内容按**可验证性**分流，不同类不同门：

| 类 | 验证方式 | 说明 |
|---|---|---|
| math | **硬验证**：sympy 等价/数值容差 + 多数投票 [A2] | v1 双门制原样适用 |
| code | **硬验证**：单测/执行器（后期通道） | 同上 |
| chinese | **软验证**：有参考→回译/对答案；无参考→自一致性（同任务多次采样结论一致）+ 内部一致性审计（无跳步无矛盾） | 忠实性红线同样适用：过程与结论不符的不收 [A2] |
| reasoning | **软验证**：自一致性 + 批判审计 | 同上 |
| misc | 软验证 + 价值分从严 | 杂项最容易变成垃圾堆，门最紧 |

提纯内核（体检→分段审计→修复→FCS→重述净化→复验）对五类**统一跑**，只是"复验"这一步按类换成硬/软验证器。修复决策树（v1 §4）原样沿用，"碰巧对/循环论证"在软验证类里同样降级。

### 7. MCP 工具面（RSI 插件对宿主暴露的接口——插件本体）

守护进程自带一个 MCP server（SME 的 MCP 是记忆面，RSI 的是提纯面，两个并列挂载进宿主）：

| 工具 | 用途 |
|---|---|
| `rsi_distill(task, thinking, conclusion?, source?)` | **主入口（T0）**：宿主 agent 把一段任务的思考轨迹+结论投喂进提纯队列，立即返回队列回执，绝不阻塞 |
| `rsi_status()` | 队列深度、各分类累计条数、最近批接受率、API 成本 |
| `rsi_query(category?, k?)` | 看已沉淀的数据样例（按类抽样） |
| `rsi_lessons(k?)` | 读当前生效的提纯教训（人查看 improver 学到了什么） |
| `rsi_set_budget(daily_cost_cap?)` | 调预算/暂停/恢复自驱出题 |

另外守护进程暴露 HTTP `/ingest`（宿主 hook 与非 MCP 外部源用）与 `/status`。

### 8. SME 配置更新（在 v1 §6 基础上的差异）

基础仍为 `kb_dynamic` 预设 + v1 的模块开关（extraction/factversion/qapair/noise/profile/namespaces/observability/WAL/maintenance 全保留），**新增/调整**：

```jsonc
{
  // 分类索引 ns：守护进程启动时确保存在
  // cls.math / cls.chinese / cls.code / cls.reasoning / cls.misc
  "namespaces": { "enabled": true, "default_ns": "cls.misc" },

  // 价值门配置化：importance_threshold 作为入索引库的下限
  "policy": { "decay_enabled": false, "importance_threshold": 0.3 },

  // 常驻形态下巩固节奏放慢（写入频率比批处理高）
  "memory": {
    "top_k": 6,
    "consolidate_every": 128,
    "compress_every": 512,
    "reinforce_on": true,
    "graph_expand": 1
  },

  // 空闲整理更积极：守护进程闲 = 提纯队列空，正好巩固
  "maintenance": { "background": true, "idle_after_s": 180, "every_s": 600 },

  "llm":      { /* 同 v1：便宜档 + reasoning_effort=none */ },
  "embedding": { /* 同 v1：本地 bge-small-zh-v1.5，零密钥 */ }
}
```

### A. CoT 提取：直接要用的方法

#### A1. 过度思考的事实基础

- **"Do NOT Think That Much for 2+3=?"**（[2412.21187](https://arxiv.org/abs/2412.21187)）：
  - 按-anchor 切 solution：每个"给出明确答案的完整段落"算一个 solution。
  - **92%+ 答对案例中第一个 solution 已正确**，首答后的思考对准确率贡献极小。
  - 极端案例：901 token 中首个正确 solution 只占 39（有效占比 4.3%）；QwQ 答 2+3 生成 13 个 solution，后 12 个全浪费。
  - 修剪变体三档：**FCS**（只留首个正确 solution）/ **FCS+Reflection**（再留一个正确 solution 保反思能力）/ **GDS**（贪心保策略多样）。
- 综述：Stop Overthinking（[2503.16419](https://arxiv.org/abs/2503.16419)）。

#### A2. 关键实证结论（直接影响管线设计）

| 结论 | 来源 | 对管线的含义 |
|---|---|---|
| 把蒸馏数据里的 "Wait"/"Hmm" 反思 token 删掉再训，基准**不降反升** | EMNLP 2025 Findings（[链接](https://aclanthology.org/2025.findings-emnlp.394.pdf)） | 这些多半是教师风格残留，可删 |
| 是否保留回溯**取决于任务结构**：搜索型难题受益，线性可解任务受损 | [2504.07052](https://arxiv.org/abs/2504.07052) | 按题型分策略，不一刀切 |
| **majority voting 是整体最佳过滤策略**（该领域消融） | OpenThoughts / [2506.04178](https://arxiv.org/abs/2506.04178) | 采样 n 条 → 群体答案过半才收 |
| 去重维度应是**推理路径等价类**而非题面 | RFT [2308.01825](https://arxiv.org/abs/2308.01825) | 同题同路径只留一条，防表层过拟合 |
| **答案对 ≠ 过程对**；CoT 不一定是真实计算的记录 | Anthropic [2307.13702](https://arxiv.org/abs/2307.13702) / [2505.05410](https://arxiv.org/abs/2505.05410) | 过程级审计不可省 |
| 只按答案过滤的自训练 → reward hacking → **突然完全崩溃** | [2505.21444](https://arxiv.org/abs/2505.21444) | 红线：过程错的轨迹绝不直接当正样本 |
| 错误数据的合法形态只有两种：**DPO 负样本** / **LEMA 式结构化纠错对** | LEMA [2310.20689](https://arxiv.org/abs/2310.20689) 等 | 见 A4 |
| s1K 仅 53.6% 轨迹完全正确仍训出强模型 | s1 [2501.19393](https://arxiv.org/abs/2501.19393) | 小规模高质量选题下轨迹含小错不致命；**规模大了必须过滤** |
| SelFee：纯 SFT 可注入自我纠正行为（数据格式：回答→自反馈→修订→终止信号链） | [2305.15923](https://arxiv.org/abs/2305.15923) | 纠正行为可以靠数据格式教 |
| 无外部反馈的自我纠错平均**降低**性能；真自我纠正需要多轮 RL（SCoRe） | [2310.01798](https://arxiv.org/abs/2310.01798) / [2409.12917](https://arxiv.org/abs/2409.12917) | v1 不指望模型自己纠，靠管线纠 |

#### A3. 过滤与修剪工具箱

- **题目侧**：只留可验证题（sympy 可解析/单元测试）；难度过滤——小模型不用 CoT 就能答对的删（Qwen3/GLM-4.5 官方做法；GLM-4.5 剔最易 50% 换来 +2-4%）。
- **答案级**：确定性验证器 > 多数投票 > 模型自评（模型只能做粗筛，**绝不当最终裁判**）。
- **步骤级**：
  - 隐式 PRM（[2412.01981](https://arxiv.org/abs/2412.01981)）：只用 outcome 好/坏样本对即可训步骤打分器，免 rollout；
  - OmegaPRM（[2406.06592](https://arxiv.org/abs/2406.06592)）：MCTS+二分定位**第一个错误步骤**；
  - Math-Shepherd（[2312.08935](https://arxiv.org/abs/2312.08935)）：对步骤前缀采样 k 次补全、以最终答对率当步骤价值（贵）。
  - 共识：PRM 当**过滤器和首错定位器**用，别当 RL 奖励源（易被 hack，R1 因此弃用）。
- **反向验证（round-trip）**：FOBAR（[2308.07758](https://arxiv.org/abs/2308.07758)）——遮住题中变量、把候选答案当已知**反推**，一致才算对。比正向自查难被骗，适合无 sympy 场景。
- **工程体检**（便宜，先跑）：n-gram 重复率、截断检测、语言混杂、循环结构。

#### A4. 错误→纠正数据的三种归宿（本项目核心）

1. **修复后收编**：定位首错 → 段级改写 → **重放复验**（修复后轨迹重推答案必须仍对）→ 干净 SFT。
2. **LEMA 结构化纠错对**（[2310.20689](https://arxiv.org/abs/2310.20689)）："错误推理+纠正+正确解"三元组，比纯正确轨迹训练效果更好；建议占最终数据 5-10%。
3. **降级为负样本/弃用**：循环论证、"碰巧对"（结论与推理无关）、修复失败 → DPO rejected 素材（v1 先存档不训练）。

#### A5. 官方 reasoning 数据清洗规则对照（抄作业清单）

| 模型 | 规则 |
|---|---|
| DeepSeek-R1（[2501.12948](https://arxiv.org/abs/2501.12948)） | sympy 验答案；滤重复/语言混杂/超长段落/代码块；RS 只留答对 |
| Qwen3（[2505.09388](https://arxiv.org/abs/2505.09388)） | 响应级六滤：答案错误 / 大量重复 / 明显猜测无推理 / **思考与总结不一致** / 语言混杂 / 疑似评测集泄漏；题级滤"无需 CoT 即可答对" |
| GLM-4.5（[2508.06471](https://arxiv.org/abs/2508.06471)） | 去重/过短/截断/格式无效 → 客观验证 → RM 过滤 → 工具轨迹须达终态；剔最易 50% prompt |

#### A6. 数据格式（已验证的模板）

- **SFT**：messages 格式，assistant 内嵌 `<think>…</think>`；多轮时非思考轮保留空 `<think></think>`（Qwen3 做法，保格式一致）。
- **DPO 对构造三模板**：
  1. 最短正确（chosen）vs 同题最长（rejected）——Do NOT Think；
  2. 最短正确 vs 正确但 ≥1.5 倍长 + 错误长回答——Kimi k1.5（[2501.12599](https://arxiv.org/abs/2501.12599)，实测 token -45% 准确率不掉）；
  3. 同预算达标 vs 超长——L1/LCPO。
- **GRPO 组内优势复用**：同题 rollout G 条，advantage=(r−mean)/std，adv>0 且最短的轨迹沉淀为 SFT 集（GLM-4.5 / Qwen3 官方思想）。

### B. RSI 循环：借鉴的机制清单

#### B1. 度量语言（来自 [lobehub/awesome-rsi](https://github.com/lobehub/awesome-rsi)）

- **task gain**：这道题变好了（最弱）
- **retained gain**：别的题没变坏
- **improver gain**：**改进器本身在变强**（唯一算真 RSI 的）
- 术语：self-refinement（不持久）< persistent SI（持久改 prompt/记忆/代码）< RSI（改进机制本身被改进）。本项目 v1 目标 = persistent SI，v2 目标 = improver gain。

#### B2. OpenEvolve（[algorithmicsuperintelligence/openevolve](https://github.com/algorithmicsuperintelligence/openevolve)，7.8k★）

- 用户契约：程序里标 `# EVOLVE-BLOCK-START/END` + 写 `evaluate(program_path) -> dict[str,float]`（多指标，越大越好），其余自动。
- 循环：岛模型（2-4 个种群隔离）+ MAP-Elites 保多样性 + 双重选择（父代按性能、灵感样本可跨岛）+ artifact 反馈（把上代报错/评估输出喂回 prompt）+ 周期迁移。
- 全组件可 seed，JSON checkpoint 血统可复现。**16GB 机器纯 API 可跑，本项目阶段二的骨架。**

#### B3. ShinkaEvolve（[2509.19349](https://arxiv.org/abs/2509.19349)，Sakana，ICLR 2026）

样本效率路线（150 次评估超 AlphaEvolve 原解）。三个可搬机制：
1. **宽松父代选择**：幂律采样 + 按"性能×新颖度/(1+已有子代数)"加权——好但被榨干的自动让位；
2. **新颖度拒绝采样**：embedding 余弦 >0.95 直接拒绝重采样（省评估钱）；
3. **meta-scratchpad**：每 10 代 meta-agent 总结评估史 → ≤5 条可执行建议附进突变 prompt（它自己进化出了 7 调用 scaffold 超过人工设计）。
另有 prompt 自进化 archive（内置 PromptBreeder）+ API 预算封顶。

#### B4. AlphaEvolve（[2506.13131](https://arxiv.org/abs/2506.13131)，未开源，机制可抄）

- **评测级联**：测试由易到难，前一关不过不进下一关（先便宜过滤）；
- **模型分工**：廉模型高频出候选 + 贵模型低频做突破；
- meta-prompt 在独立数据库里共同进化。

#### B5. Darwin Gödel Machine（[2505.22954](https://arxiv.org/abs/2505.22954)）——防退化教科书

- **archive 血统树只增不减 = 天然回滚**：父代按性能加权抽样，允许回到任意祖先重启支线；
- 每次只评锚点问题的**随机子集**（防过拟合固定测试集）；
- held-out 与 evaluator 对被进化对象不可见（防偷改评测）；
- 基座权重不动，只进化 scaffold（限制爆炸半径）。SWE-bench 20%→50%。

#### B6. GEPA / DSPy（prompt 进化，免训练）

- GEPA（[2507.19457](https://arxiv.org/abs/2507.19457)，已并入 [DSPy](https://github.com/stanfordnlp/dspy)）：LLM proposer **读运行轨迹反思**→变异 prompt；候选池只保留"分数×长度"**帕累托前沿**；比 GRPO 平均高 6% 且省 35 倍 rollout。**本项目中"提示词自主进化"的蓝本。**

#### B7. 数据闭环家族（SFT 层的祖先们）

- STaR（[2203.14465](https://arxiv.org/abs/2203.14465)）：采样→留答对→SFT→迭代；
- ReST-EM（[2308.08998](https://arxiv.org/abs/2308.08998)）：Grow（采样建库）与 Improve（训练）解耦，训练期数据冻结防漂移；
- Self-Rewarding（[2401.10020](https://arxiv.org/abs/2401.10020)）：多候选自评造偏好对→DPO→迭代。
- 本项目 v1 = 上述闭环的"数据生产半边"（只 Grow 不 Improve，不训练）。

#### B8. 明确不碰的（记录在案）

SEAL（自编辑权重）、Absolute Zero（自博弈多卡 RL）、DGM 完整版（SWE-bench 基建）——机制已吸收进设计，实现跳过。

### C. 记忆系统速查（SME 的定位）

- 三层记忆共识：**参数记忆**（慢、稳、难更新）/ **上下文**（快、易失）/ **外部检索记忆**（显式、可增删改、可审计）→ 冻结参数 + 外部记忆承接全部易变信息 + 异步巩固管道。
- CLS 互补学习系统：海马（快/稀疏/易变）↔ 新皮层（慢/稠密/稳定），睡眠重放+交错巩固 = sleep-time compute（[2504.13171](https://arxiv.org/abs/2504.13171)）。
- 再巩固：记忆被提取后才可改写 → 检索触发的 UPDATE（A-Mem / Mem0 四操作）。
- 遗忘是特性：记忆库要主动做减法，否则检索污染（裸 RAG 越用越糟的根源）。
- **SME 在本项目中的角色 = improver 的海马体**：题目库索引、错误模式库、教训库（会取代更新，factversion）、提示词血统库、自画像统计（profile）。原始 trace 走文件系统，SME 只存索引卡与经验——大对象不进记忆库。

## 仿生画像与底色预训练调研

> 调研 agent 全文要点存档，供随时翻查。带 arXiv 编号/链接的为文献依据，其余为工程经验值。

### A. 仿生人格数值系统

#### A1. 分层状态机（推荐架构，本表即 biodata 模块的实现规格）

| 层 | 维度 | 取值 | 时间尺度 | 更新律 | 依据 |
|---|---|---|---|---|---|
| 特质层 | Big5+H（真诚-谦逊）T 分 | 20–80，基线 50±10 | 月~年 | 慢速贝叶斯收缩：T_new = T_old + (N/(N+50))·δ，单事件 Δ≤0.1 | Soto & John 2017 BFI-2；HEXACO Ashton&Lee |
| 心境层 | PAD 三维（愉悦/唤醒/支配） | [-1,1] | 半衰期 12–48h | EMA α=0.15–0.3 + 均值回归基线 | Mehrabian PAD；ALMA (Gebhard 2005) |
| 情绪层 | Ekman-6 × 强度 | 强度 0–100 | 分钟级 | 跳变+衰减 E(t)=E₀·0.95^t | Ekman 1992；ALMA |
| 需求层 | 精力/压力/好奇/社交/自主/胜任 | 0–100 稳态 | 小时级 | 指数衰减+事件脉冲（稳态 RL） | Keramati & Gutkin 2014；SDT (Ryan&Deci 2000)；Sims motives |

#### A2. 防漂移三件套（必须全上）

1. 均值回归：所有状态向基线指数回归；
2. 硬夹断：状态 ∈ 基线 ±2SD；
3. 周期再锚定：基线每 50 轮会话/2-4 周重估（会话末状态 EWMA，权重 0.9 递减）；特质基线变动需 ≥10 个同向独立事件。

#### A3. LLM 打分的加固（LLM 量表信度差，EMNLP 2024 实证）

- 锚定行为示例的 rubric 而非抽象量表；
- 只输出离散整数 Δ 并限幅（-2~+2）；
- （进阶）3 次采样取中位/强迫选择成对比较。

#### A4. 关键参考

- 情绪惯性 AR(1)：xₜ = b + φ·xₜ₋₁ + ε，φ≈0.3–0.6（Koval & Kuppens 2016）；
- 享乐设定点 ODE 模型（MBE 2021）；Sims 性格 trait 修改 motive 衰减率（arXiv:1508.00377）；
- Generative Agents（arXiv:2304.03442）：记忆流三因子检索 + reflection——"对话事件→画像更新"骨架；
- 开源参考：airi、AI-tamago、desktop-companion（valence/arousal 双维）、companion-emergence；
- 数值→输出可控：Big5-Chat（2410.16491）、Machine Mindset（2312.12999）、Persona Vectors（2507.21509）、EmotionPrompt（2307.11760）。

### B. 个人底色预训练

#### B1. 量级与路线

个人语料 0.5–1.5 千万 token vs 基座 140B——占比万分之一。**CPT 目标=token 分布/风格先验偏移，不是注入知识**（DAPT 实证：低资源域也稳定涨点，arXiv:2004.10964）。

#### B2. 配方（有消融依据）

- 个人：通用 = **1:4~1:9**（回放 5–15% 即显著防遗忘，社区 25–50% 更保守）；
- 总曝光 **≤4 epoch**（arXiv:2305.16264：4 后价值骤减）；
- LR 5e-6~5e-5（基座峰值 1/10 以下），无 warmup，cosine 衰到底（arXiv:2407.07263）；
- **LoRA 学得少忘得少**（arXiv:2405.09673）：底色 CPT 用全参或 rank≥128/ReLoRA；风格 SFT 用 rank 16–64；
- 风格 SFT：epoch 1–3，LR 1e-4~5e-5（WeClone 16k★实践值，过拟合表现为复读）。

#### B3. 保守清洗（保底色的关键）

- 只做：①安全/PII 过滤 ②去重（MinHash **阈值放宽**防误杀口头禅）；
- 跳过：句长/词长/停用词比/困惑度过滤——C4 审计实证（arXiv:2104.08758）这些规则**不成比例删除口语化与非主流文体**；
- 短消息、口头禅、语气词、表情符号全部保留（它们正是风格）。

#### B4. 语料形态配比

个人预训练混合 = **对话转录 ~50% + 第一人称叙事自传 ~30% + 风格保持改写 ~20%**（改写提示词显式要求保留句长分布/口头禅/标点习惯，原文:改写=1:1~1:2）。

#### B5. 主观事实处理

- 一律第一人称叙事进 CPT（"我觉得/我经历过"），不做百科式断言；
- **事实查询走 RAG/记忆库，不入权重**（Second Me/MemGPT/Generative Agents 一致分工）；
- 自传体记忆三层：原子事实（时间戳/置信度/主客观标签）→ 情景片段 → 反思概括。

#### B6. 记忆化风险

逐字记忆化在前几个 epoch 暴涨且早于验证指标恶化（arXiv:2406.11507）——不能只看 loss，要测抽取率；个人场景"背出隐私原文"风险高。
