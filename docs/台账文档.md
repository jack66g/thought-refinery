## 本轮优化与验收

本轮在现有 MCP、daemon、SME REST 和三线 JSONL 框架内完成以下改动。

- CoT 的修复和净化需要复审，重复可疑轨迹进入候选负样本。数值比较保留括号，能限定形式的算术与整数同余题使用独立求解，其他题型由只看题面的模型探针复核。错误结论、复审失败和未配对 DPO 均有回归用例。
- 在模型调用、训练落盘、SME 出站和历史读取边界处理可识别敏感字段。观察者核对用户引文，叙事记录证据，风格目标只替换敏感片段。文本规则覆盖的范围以项目实现和合成标记测试为准。

- 四层画像的特质单次变化收敛到计划上限 0.1。预训练按捕获周和心境采样，数据足够时任何桶最多占一半，缺桶写入清单。冻结导出按会话、题面和派生血缘切分，保留风格目标索引和 CoT 目标索引，旧门控版本先做质量复审再入导出。

### 1. 框架与验收基准

以 [V2 设计](设计文档.md#v2-常驻提纯设计) 的常驻插件、进程外 SME、分类沉淀和双门为底座，以 [V3 计划书](设计文档.md#v3-仿生画像与三线设计) 的四项已定决策为验收依据。

- **接线**采用宿主 MCP 或 HTTP 适配、daemon 队列和 SME REST。源轨迹与训练文件由 RSI 管理，SME 保存可检索的索引、主观事实和画像摘要。
- **CoT**保留分段过程审计、结论验证、四级查重和分类 JSONL。修复、LEMA、DPO 三种归宿各有独立的放行条件。对话没有推理轨迹时，另外两条产品线仍可单独收样。
- **个人底色 CPT**保留用户原话转录、带 `subjective_fact` 的第一人称叙事、保留个人表达特征的改写。保守清洗围绕隐私、来源和查重，情绪与时间参与训练组装。
- **风格 SFT**保持用户原话作为 assistant 目标。脱敏只替换敏感片段，原有语气与标点作为质量指标。
- **仿生与自探索**保留 Big5+H、PAD、Ekman-6 和六项需求四层，以及均值回归、限幅、基线重估。自驱出题和自探索继续独立开关、默认关闭、受预算与配额约束。元学习仍沉淀教训，发布候选改进需经过固定评估集。

```text
宿主 MCP / HTTP → 适配和队列 ┬→ CoT 过程门与答案门 → 分类 JSONL
                            ├→ 用户转录 / 主观叙事 / 风格改写 → CPT JSONL
                            └→ 角色对调和目标检查 → 风格 SFT JSONL
观察者 → 四层画像 → 心境标签和受控探索
数据索引 / 主观事实 / 画像摘要 / 教训 → SME REST → 检索或离线补写
```

#### 2.2 真模型分流与抽样质检

两次真模型分流共 15 次角色调用，模型地址与配置结构沿用现有实现。下面是小样本功能验证，质量或通过率须用按来源分层的独立评估集量化。

| 输入 | CoT | CPT | 风格与 SME |
| --- | --- | --- | --- |
| 合成展板对话加简单算术 | 正确答案 16，价值门 4.6 低于 6.0，CoT 零产出 | 1 转录、4 主观叙事、1 改写 | 2 条风格样本，SME 可检索到 4 条主观事实 |
| 合成展板对话加最小正整数证明 | 价值门 7.95，过程审计清洁，软验 100%，收 1 条 CoT | 1 转录、3 主观叙事、1 改写 | 2 条风格样本，SME 写入 1 条 CoT 索引和 4 条主观事实 |

- **CoT 抽读**。真模型样本给出 `n=346`。人工回代核对 7、11、13 的余数为 3、5、8，并用周期 1001 验证最小正解。FakeLLM 的 3 条均满足 messages、`<think>` 和结论结构，但净化桩产生了“最后用十六”“随后把十三加入八得到二”“四条边相加等于”等不完整片段。它们能验证流水线通畅，也暴露净化后缺少充分复核。
- **CPT 抽读**。转录保留了合成用户的展板经历，未混入助手特征串。改写保留“先写最重要的话、稍后补齐”的意思并关联原转录。真模型叙事补入了“拼装费劲”“字写得不算好看”“怕折了角”等原文无依据的细节，部分叙事虽是第一人称，也只能作为待审派生文本。
- **风格抽读**。合成普通样本的目标是用户的节奏偏好和收尾原话，角色对调符合设计。带合成邮箱的样本也进入了风格 SFT，邮箱仍在 assistant 目标中。同一测试的 CPT 文件已遮盖该标记。应对整组 messages 做隐私验收，评估语气保真时以脱敏后的原话为基准。
- **分布和漏斗**。该批 9 条 FakeLLM CPT 均落入 neutral，不能估计平衡效果。另做受控采样，1 条积极、9 条平稳且每桶上限为 5 时，输出 1∶5，平稳占 83.3%，且先取文件顺序最早的转录。现有采样只实现单桶截断，尚未兑现 manifest 中任一桶不超过 50% 或时间覆盖的约束。

### 4. 调研如何落到现有框架

#### 4.1 生物学启发与心理测量

稳态强化学习研究用内部状态和设定点讨论动机，支持把误差反馈、半衰期和适度回归用作工程设计。Whole Trait Theory 将长期特质与跨情境状态分布联系起来，支持从多会话斟酌慢变量。项目四层继续表达文本中观察到的信号，0.1、24 小时及各脉冲强度作为可验证的工程先验。六项需求的变化由文本证据、时间和置信度驱动，避免把某次措辞当成长期个性。 [Keramati 和 Gutkin](https://elifesciences.org/articles/04811) · [Fleeson 和 Jayawickreme](https://pubmed.ncbi.nlm.nih.gov/26097268/)

建议用同一人多会话、情绪反讽、助手话语误混、重复重放、不同等义措辞和长时间空窗做观察者台架。对 PAD 分桶分别标注捕获时即时线索和维持状态，对四层报告有证据比例、重测一致性和每周漂移。对一部分样本实行独立盲审，分歧时记录未知并减少更新权重。自探索只消费稳定且有依据的需求缺口。

#### 4.2 过程验证、训练和数据

过程监督在数学任务上显示了逐步判定的价值，CoT 忠实性研究也给出了貌似合理却漏报影响因素的例子。RSI 的双门因此需要分别验证过程与答案，净化后检查关键前提、运算和结论。LEMA 给出从错误迹线与可靠纠正中学习的试验证据。保留同题错误证据和已复审纠正两个部分，训练导出只接收成对记录。 [Lightman 等](https://arxiv.org/abs/2305.20050) · [Turpin 等](https://arxiv.org/abs/2305.04388) · [LEMA](https://arxiv.org/abs/2310.20689)

去重研究观察到重复、记忆化与测试污染的关系，C4 审计表明过宽的黑名单会改变保留下来的文本分布。RSI 应保持 CPT 的保守清洗，用来源隔离和实验集查重来控制污染。按会话和派生血缘划分训练集与评估集，转录及其改写保持同组。数据卡逐次记录来源授权、时间、用途、语料配比和可删除索引。训练后的抽取测试采用专门的合成金丝雀。 [Lee 等](https://arxiv.org/abs/2107.06499) · [Dodge 等](https://aclanthology.org/2021.emnlp-main.98/) · [Datasheets for Datasets](https://arxiv.org/abs/1803.09010) · [Carlini 等](https://arxiv.org/abs/2012.07805)

有限数据训练研究发现少量重复在其评测条件下仍有价值。继续预训练研究给出了 replay、学习率调度和防遗忘的实验依据。项目原定个人对通用 `1:4` 到 `1:9` 与最多 4 个个人样本曝光周期作为首轮候选。训练前按 token 和同源族统计有效曝光，使用固定基座、固定算力和留出评估对比两端配比、低曝光基线及通用能力回归。先冻结数据，再分别评估 CPT、CoT SFT 和风格 SFT 的收益。 [Muennighoff 等](https://arxiv.org/abs/2305.16264) · [Ibrahim 等](https://arxiv.org/abs/2403.08763) · [Parmar 等](https://arxiv.org/abs/2407.07263)

#### 4.3 RSI 闭环

STaR 用结果反馈补充推理训练数据，Darwin Gödel Machine 用分支档案保存候选并在任务上评价，GEPA 展示了提示词与执行轨迹反馈的迭代方式。RSI 可沿用已有元学习和提示词血统规划，把更新对象限定为候选提示词与数据配方，按同预算 A/B 选择。新教训先进入 SME 待评估区，固定留出集评估后再晋级并保留上一版本可回滚。训练使用冻结快照，自生成样本带血统标签并设置占比，配合独立人源样本与分布监控抑制反馈退化。 [STaR](https://arxiv.org/abs/2203.14465) · [Darwin Gödel Machine](https://arxiv.org/abs/2505.22954) · [GEPA](https://arxiv.org/abs/2507.19457) · [Shumailov 等](https://arxiv.org/abs/2305.17493)

### 5. 优化次序与验收门槛

下表阈值是拟议工程门槛。建立固定基线后可按样本量和业务分布校准，CoT 双门、隐私哨兵和发布前校验按零容忍执行。

| 顺序 | 实施点 | 交付验收 |
| --- | --- | --- |
| P0.1 双门与终稿复核 | 复审可疑直接归入待审或负样本候选。净化后校验关键步骤的保真。确定性题用限定语法的解析、小型独立验证器和精确数值语义。自由题独立答题或用证据一致性检查，比较阶段才引入参考结论 | 固定反例集覆盖答案碰巧对、运算优先级、严格数值等价、旧软验回声、净化截断与审计缺字段。已知错误进入正样本为 0，LEMA 纠正通过复审，DPO 未配对记录排除于训练导出 |
| P0.2 数据与预算边界 | 对送模型前、JSONL 和日志前、SME 入库前实施一致的敏感字段处理。在受控存储中保存来源证据或脱敏定位符。叙事增加断言与出处映射。接入模型 usage，区分重试、缓存与合理余量，将费用门统一到所有调用 | 合成邮箱、账号、凭据哨兵在各导出与网络请求体中为 0。证据审核集中无新增无依据叙事。跨摄取、教训和出题的并发额度测试在上限前拒绝新调用，状态给出拒绝原因 |
| P1.1 可回放数据流 | 明确接收、处理中、三线完成、索引待补写及失败状态，使用来源事件键贯通三线和 SME。重试同事件只更新一次画像和每条独立产物。落盘快照可重建对账 | 同事件并发重投、落盘中断、超时、断网、重启后进行逐事件对账。有效样本无漏记，画像无重复推进，已确认写入无重复索引，失败有明确去向 |
| P1.2 画像和训练清单 | 措施先按 V3 计划修正慢层单次限幅。使用捕获时间做分层，按会话及派生族隔离切分，情绪与时间共同组装 CPT，分桶不足时显式记录。增加状态质量与可回放测试 | 时间乱序、跨周偏态、缺桶、小样本和切分泄漏均有固定测试。可达时任一情绪桶不超过 50%。重复执行同冻结清单可重现样本、token 数和组别 |
| P2 导出与训练小试 | 三条线依次进行 schema、tokenizer、chat template、CPT EOS、CoT 和风格 loss mask 冒烟。使用同基座和预算对比原始转录、加入经审叙事和改写、CoT 和风格适配的影响 | 每条训练记录可导入并能追溯，题族和派生族跨切分重复为 0。分别报告通用能力、推理正确率、过程正确率、风格盲评、主观事实一致率及合成秘密抽取率，候选方案过回归阈值后再扩大 |
| P3 常驻观察与受控 RSI | 用 24 小时 FakeLLM 及真 SME 验证队列、回放、时间分桶、配额日切和内存增长。少量人工挑选的真模型样本用于质量标定。对提示词候选运行冻结评估和对照试验 | 按来源与类别记录完成率、重复率、P50/P95 延迟、恢复时间、成本及改进收益。优先提高“经过复核的有效记录/单位成本”，把接受率与质量、拒收原因一起解释 |

质量基线建议先建立小型人工集。按宿主、题型、正确与错误轨迹、情绪桶和时间窗口留样，同一会话内的转录、叙事和改写穿透审计。用负例专门挑战两个验收门，使用经人工核定的困难题测召回。等 P0 通过后再安排训练小试，当前测试已覆盖可运行性和部分数据契约，GPU 训练收益、可选向量模型以及 24 小时稳定性仍需独立验收。

### 6. 如何隔离复跑 MCP 和回归测试

在单独 PowerShell 进程里，从 ThoughtRefinery 根目录运行下列步骤。项目副本、uv、CPython、虚拟环境、依赖缓存、绘图库缓存与测试产物放入同一个临时根目录。复跑回归不需要 DeepSeek 密钥。

```powershell
$testRoot = Join-Path ([IO.Path]::GetTempPath()) ("rsi-audit-" + [guid]::NewGuid())
$mainCopy = Join-Path $testRoot "thought-refinery"
New-Item -ItemType Directory -Path $testRoot | Out-Null
git clone --local --no-hardlinks . $mainCopy
git clone --local --no-hardlinks ./spatial-memory-engine (Join-Path $mainCopy "spatial-memory-engine")

$env:TEMP = $testRoot
$env:TMP = $testRoot
$env:PYTHONUTF8 = "1"
$env:NO_PROXY = (@($env:NO_PROXY, "127.0.0.1", "localhost") | Where-Object { $_ }) -join ","
$env:UV_NO_CONFIG = "1"
$env:UV_CACHE_DIR = Join-Path $testRoot "uv-cache"
$env:UV_PYTHON_CACHE_DIR = Join-Path $testRoot "python-cache"
$env:UV_PYTHON_INSTALL_DIR = Join-Path $testRoot "python"
$env:UV_PYTHON_BIN_DIR = Join-Path $testRoot "bin"
$env:MPLCONFIGDIR = Join-Path $testRoot "matplotlib-config"
$env:HF_HOME = Join-Path $testRoot "huggingface"
$env:HF_HUB_OFFLINE = "1"
$env:TRANSFORMERS_OFFLINE = "1"

$uvTarget = Join-Path $testRoot "uv-tool"
py -3.10 -m pip --disable-pip-version-check install --no-cache-dir --target $uvTarget "uv==0.13.9"
$uv = (Get-ChildItem -LiteralPath $uvTarget -Recurse -Filter uv.exe | Select-Object -First 1).FullName
& $uv python install 3.11.18 --no-bin
Set-Location -LiteralPath $mainCopy
& $uv venv --managed-python --python 3.11.18 .venv
$testPython = Join-Path $mainCopy ".venv\Scripts\python.exe"
& $uv pip install --python $testPython -r requirements.txt -e "./spatial-memory-engine[multipart,viz]"

& $testPython -m pytest -q rsi/tests/test_mcp_server.py --basetemp (Join-Path $testRoot "pytest-mcp")
& $testPython -m pytest -q rsi/tests --basetemp (Join-Path $testRoot "pytest-rsi")
Set-Location -LiteralPath (Join-Path $mainCopy "spatial-memory-engine")
& $testPython -m pytest -q -rs experiment/regression --basetemp (Join-Path $testRoot "pytest-sme")
```

真实端到端复跑使用两个空闲环回端口，复制 RSI 与 SME 配置到临时目录并改端口和 SME 地址。以正常模块入口启动两服务，进程级配置模型密钥，保持两种自驱开关关闭。依次投喂含完整证明的多轮合成对话、原样重投、无思考纯聊天，按 `event_id` 检查 `/status`、CoT、风格和预训练文件及 SME 搜索。合成隐私哨兵、重复复审失败和断线故障用离线 FakeLLM 台架。全部服务退出后，可删除本轮临时根目录。 [Astral uv 管理 Python](https://docs.astral.sh/uv/concepts/python-versions/) · [uv 环境变量](https://docs.astral.sh/uv/configuration/environment/)
