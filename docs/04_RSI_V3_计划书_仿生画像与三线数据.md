## 2. 清账清单（做完一项勾一项，台账同步）

- [ ] **T1 biodata 状态机**：四层数值模型 + 更新律（EMA/贝叶斯收缩/衰减脉冲）+ 防漂移三件套 + 持久化(biodata/state.json + history.jsonl) + SME 索引卡(rsi.biodata)
- [ ] **T2 观察者提示词 biodata_observer**：锚定行为 rubric，输出离散 Δ(-2~+2 限幅) + 主观事实抽取（一石二鸟：打分的同时抽既定事实）
- [ ] **T3 叙事化提示词 fact_narrator**：主观事实 → 第一人称叙事短文（subjective_fact 标签）
- [ ] **T4 三线分流器 splitter**：一个事件 → CoT线（原有管线）+ 预训练线 + 风格SFT线；适配器补传 transcript（完整对话轮）
- [ ] **T5 预训练线落盘**：dataset/pretrain/{transcripts,narratives,rewrites}.jsonl，保守清洗（PII+宽松去重 jaccard 0.9），每条带 mood_tag（捕获时刻心境 P 值分桶）
- [ ] **T6 风格SFT线落盘**：dataset/style/{sft}.jsonl（assistant=用户原话，WeClone 式）
- [ ] **T7 时间平衡清单**：_meta/pretrain_manifest.json——各线条数/情绪分桶分布/混合配方（1:4~1:9 回放、≤4 epoch、lr 建议）+ 平衡采样函数（按情绪桶配额抽样出 train 子集）
- [ ] **T8 自适应出题 v2**：proposer 提示词加"难度锚"（当前已收 CoT 的平均长度/通过率），出题难度 = 锚 +1 档；仍走 self_propose 开关（默认关）
- [ ] **T9 自探索模块**：需求层→任务类型映射 + explore_mission 提示词 + MCP 工具 rsi_next_mission() + HTTP /next_mission；独立开关 self_explore.enabled（默认关）+ 日封顶
- [ ] **T10 测试全绿**：biodata 更新律（确定性数学）/分流路由/保守清洗/叙事格式/manifest/自探索生成/FakeLLM 全链路；真模型冒烟 observer+narrator 各 1 条

## 3. 关键参数表（全部来自调研，改动需台账记原因）

| 参数 | 值 | 来源 |
|---|---|---|
| 特质层收缩系数 k | 50（T+=N/(N+50)·δ），单事件Δ≤0.1 | A1/A2 |
| 心境 EMA α | 0.2；半衰期 24h（均值回归） | ALMA/Gebhard 2005 |
| 情绪衰减 | 0.95^t（会话内分钟级） | ALMA |
| 需求衰减 | 每小时向稳态点回归 10%（τ≈10h），事件脉冲 ±15 | Keramati 稳态RL |
| 硬夹断 | 各层 ∈ 基线±2SD | A2 |
| 基线重估 | 每 50 次更新，EWMA(0.9) | A2 |
| 预训练去重阈值 | jaccard ≥0.9 才判重（放宽防杀风格） | B3 |
| 预训练 epoch 上限 | 4（写进 manifest 训练须知） | 2305.16264 |
| 混合配方 | 个人:通用 = 1:4~1:9 | B2 |
| 风格SFT样本形态 | 多轮上下文 + assistant=用户原话 | WeClone |
| mood 分桶 | P>0.2 积极 / <-0.2 消极 / 其余平稳 | 本设计（PAD P 维） |

## 4. 数据"拿走即训"标准（三线各自的验收线）

- **CoT 线**：V2 标准（双门+提纯+查重）不变；
- **预训练线**：纯文本行 {text, meta}；只做 PII+宽松去重；第一人称叙事带 subjective_fact 标签；manifest 注明 epoch≤4 与回放配方；
- **风格SFT线**：messages 格式，assistant=用户原话（不做风格修正），去重按题面+回复联合指纹。
